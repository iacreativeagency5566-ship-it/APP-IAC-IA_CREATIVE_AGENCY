# IA Creative Agency — Next.js

    npm install && npm run dev

- Imágenes, video, capas parallax, esfera: `lib/media.ts` + archivos en `public/media/`.
- Textos, paquetes y testimonios: `lib/content.ts`.
- Componentes en `components/ui/` con los mismos nombres/exports que los de 21st.dev:
  puedes pegar el código oficial encima de cada archivo sin cambiar `app/page.tsx`.
- Edición visual: abre la carpeta en Onlook (Next.js + Tailwind).
